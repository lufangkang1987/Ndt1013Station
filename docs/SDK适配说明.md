# SDK 适配记录

参考文件：`Help/Doc/903-341-80_SDK_ProgrammingGuide_NDT1012&1417MA_CH_A0.pdf`（2020-07-09，A0）。此文件明确面向 NDT1012/1417MA；用于通用接口参考，不作为 NDT1013LA 专属硬件能力证明。

已参考的通用约定：

- 使用工作目录和回调函数创建探测器对象，按返回值判断创建是否成功。
- Create 失败时可能返回被占用设备的 ID，应用不得把这个 ID 当成自己创建成功的实例销毁；工程已对此处理。
- 动态解析 Create、Destroy、GetAttr、Invoke 等导出函数。
- 命令可能立即完成或进入异步等待；任务成功、失败、取消事件的首参数对应命令 ID，失败事件第二参数为错误码。
- 回调中避免长时间阻塞，图像数据应在回调有效期内深拷贝。
- Destroy 用于断开并释放探测器对象；销毁回调边界仍须在实际 SDK/固件组合中确认。

设备适配以发行包 `Dev/work_dir/NDT1013LA` 为起点，已随项目收录到 `third_party/iray/work_dir/NDT1013LA`。构建和运行不再依赖原发行包目录；在复制出的运行目录中配置，不改动项目内厂商原始配置。连接层没有自动更改 IP、触发方式、UserRAM 或固件配置。

当前实机采集入口为 Cmd_ClearAcq，对照包内 Dynamic_SingleAcq 示例。该示例还显式设置 SyncOut、写 UserRAM 和曝光窗口；由于其与当前实机的适用性尚未验证，工程没有照搬这些写入操作。因此该入口属于待联调入口，不承诺任意现有触发配置下均可出图。

正式采集版需补齐：能力与属性范围查询、适用于实机的触发流程、参数回读、校正模板有效性确认、SDK 工作线程、Abort/Stop 与销毁策略、图像序号/校正元数据、持续存储和异常恢复测试。
